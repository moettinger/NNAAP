# Nurse Aide Skills Practice

Personal study quiz for the Virginia NNAAP skills evaluation. Static site, no build step.

- `index.html`, `style.css`, `app.js`: the quiz, mock exam and weak-spot tracking (progress is stored in the browser's localStorage).
- `data/skills.js`: the 22 tested skills from Credentia's "VA Skills Listing for the 2023 NNAAP" (Skill 12 is marked not tested), with critical-element flags, order groups and study notes.

Skill steps are Credentia's wording and remain their copyright; this is a private study aid, not for redistribution.
